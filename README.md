# Anderson Engineering

The course site for Anderson Engineering, a library of university-level engineering courses, each short enough to finish in about an hour. It is part of Anderson Academy.

Public URL (once the domain is registered): https://andersonengineering.app/

GitHub Pages URL: https://nakamotopublius.github.io/andersonengineering/

Course pages use lowercase-with-hyphen slugs without the Brief letter B, for example `/engr-501` for ENGR 501 B, Calculus One.

The backbone of the Foundations courses is MIT OpenCourseWare, credited on each course page and in each Course Book, under a Creative Commons Attribution-NonCommercial-ShareAlike licence where that licence applies. The wording of the Brief courses is original to the Academy.
